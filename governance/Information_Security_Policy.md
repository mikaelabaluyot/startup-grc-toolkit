# Information Security Policy

## Purpose

To establish baseline security requirements for protecting ReWire.U information assets, customer data, and technology resources.

## Scope

This policy applies to all employees, contractors, systems, applications, and data used by ReWire.U.

## Security Principles

ReWire.U follows the listed security principles:

- Multiple Layers of Security Controls
- Least Priviledge
- Secure by Design
- Data Protection by Default
- Continuous Improvement

## Access Control

- Access needs to be granted based on business need and the principle of least privilege.
- Administrative access restricted to authorized personnel use.
- Quarterly review of access permission.
- Multi-Factor Authentication (MFA) must be enabled for all employee accounts and is mandatory for privileged accounts.

## Data protection 

- Sensitive health information must be protected against unauthorized access.
- Data must be protected at all times.
- User's personal data must be processed in accordance with GDPR requirements.

## Incident Reporting

Employees must report to the designated security contact suspected:

- Security incidents
- Data breaches
- Unauthorized access
- Phishing attemps

## Complience

The company uses the following frameworks and regulations as guiding references for its security program:

- GDPR
- NIST Cybersecurity Frameworks (CSF) 2.0
- ISO/IEC 27001:2022

## Review

This policy should be reviewed annually or following significant business or security changes.
