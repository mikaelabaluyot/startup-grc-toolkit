# Control Mapping

## Overview

This folder contains the security controls selected to reduce identified cybersecurity and compliance risks for ReWire.U.

The controls are mapped against recognized cybersecurity and compliance frameworks to demonstrate how security measures support risk reduction and regulatory requirements.

---

## Frameworks Referenced

- General Data Protection Regulation (GDPR)
- NIST Cybersecurity Framework (CSF) 2.0

---

## Control Mapping

The file `Controls.md` maps identified risks to:

- Security controls
- Relevant GDPR requirements
- Applicable NIST CSF 2.0 categories

---

## Purpose

The purpose of control mapping is to demonstrate how risks can be reduced through the implementation of appropriate security controls.

Examples include:

| Risk | Control |
|--------|--------|
| Password reuse | Multi-Factor Authentication (MFA) |
| Phishing attacks | Security awareness training |
| Unpatched vulnerabilities | Vulnerability management |
| Database misconfiguration | Configuration management |
| GDPR non-compliance | Privacy governance processes |

---

## Key Takeaway

Risk management is not only about identifying risks. It also requires selecting and implementing controls that reduce the likelihood or impact of those risks while supporting business and compliance objectives.
